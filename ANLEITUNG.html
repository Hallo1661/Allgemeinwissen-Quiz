WISSENSRAUM

Von der ZIP zum eigenen Quiz.

Enthalten sind 3.013 Fragen. Das Ziel von 5.000 wurde nicht erreicht; 1.987 fehlen. Der Bestand ist literaturlastig. Prüfumfang und Grenzen

Direkt auf deinem Computer starten

  1. Die ZIP vollständig entpacken.
  2. index.html doppelt anklicken.
  3. Antwort auswählen oder eintippen und Antwort prüfen drücken. Die Bewertung und Lösung erscheinen sofort.

Auf GitHub Pages veröffentlichen

  1. Auf GitHub ein neues öffentliches Repository erstellen, zum Beispiel wissensquiz.
  2. Add file → Upload files öffnen. Alle entpackten Dateien dieses App-Ordners hochladen. index.html muss direkt in der obersten Ebene liegen. Nicht die ZIP hochladen.
  3. Mit Commit changes speichern.
  4. Settings → Pages öffnen.
  5. Unter Source die Option Deploy from a branch wählen. Branch main, Ordner / (root), anschließend Save.
  6. Nach einigen Minuten zeigt GitHub dort deinen Website-Link an. Er sieht etwa so aus: https://DEIN-NAME.github.io/wissensquiz/.

Kein Terminal, Build oder API-Schlüssel erforderlich. Quellen- und Lizenzdateien mit hochladen. Offizielle GitHub-Anleitung

Fehler zum Lernen nutzen

Weiß ich noch nicht deckt die Lösung auf. Mit Fehler wiederholen übst du Fragen, die du zuletzt falsch beantwortet hast. Der Fortschritt bleibt nur in diesem Browser gespeichert.
